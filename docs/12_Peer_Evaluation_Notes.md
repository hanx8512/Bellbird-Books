# Peer evaluation preparation

Each member must complete the peer evaluation individually and confidentially.
The supplied form has only two member columns; this project has three members,
so add a third column before filling it.

## Recommended columns

| Evaluation criterion | Your name: 李宁杰 | Group member: 杨世垣 | Group member: 刘汉 |
| --- | --- | --- | --- |
| Attends meetings regularly and arrives on time | | | |
| Contributes meaningfully to discussions | | | |
| Carries out tasks without depending on others | | | |
| Demonstrates quality work for the agreed role | | | |
| Demonstrates a cooperative and supportive attitude | | | |
| Contributes significantly to the assessment | | | |
| Total | | | |

Use 5 = strongly agree, 4 = agree, 3 = neutral, 2 = disagree, 1 = strongly
disagree. Do not ask another person to fill your ratings.

## Workload allocation

- 李宁杰: QA, CI, used-book module, supplier import, test evidence, release.
- 杨世垣: project management, catalogue, section inventory, data model.
- 刘汉: storefront, special orders, reservations, state machine, search.

Adjust the wording to reflect the work that actually happened. If a member did
less than planned, record the real contribution and discuss it with the team
before submission.

## Team dynamics prompts

- How effectively did the group communicate and make decisions?
- Which behaviours helped the team most?
- Which behaviours created risk or delay?
- What will you carry into the next group project?
