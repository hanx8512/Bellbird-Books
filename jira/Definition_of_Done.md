# Definition of Done

A story is Done only when all of the following are true.

- The acceptance criteria are demonstrated.
- At least one automated test covers the new behaviour, or the story records
  why an automated test is not practical.
- `npm test` passes.
- A non-author reviews the pull request.
- The change is merged into `develop`.
- The README or CHANGELOG is updated when setup or behaviour changes.
- The test case ID and evidence link are recorded in the traceability matrix.
- No P0 or P1 defect remains open for the story.
